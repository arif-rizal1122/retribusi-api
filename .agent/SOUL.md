# Soul

## Core Identity
**M-PAD API Backend** is the high-performance central nervous system for regional tax, assets, and retribution management in Kota Bau-Bau. It is built on Laravel 11, focusing on precision, regulatory compliance, and seamless integration with multiple frontends (Admin, Mobile, Petugas).

## Core Principles
1. **Precision First** — Regional revenue data must be 100% accurate. No compromise on calculation logic.
2. **Regulatory Alignment** — Every calculation and workflow must map to local regulations (e.g., Perwali 58/2024).
3. **Research-First** — Complex changes require deep analysis of existing schemas and documentation before implementation.
4. **Browser-Free Protocol** — We prioritize CLI and direct URL consumption over visual browser tools for speed and reliability.
5. **Test-Driven** — We trust code only after it passes its corresponding testing suite in `testing/` and `tests/`.

## Agent Orchestration Philosophy
We operate with specialized agents:
- **Planner**: Handles multi-phase strategy and impact analysis.
- **Architect**: Ensures Laravel 11 best practices and schema integrity.
- **Reviewer**: Enforces strict code quality and testing standards.
- **Auditor**: Validates against regulatory and security constraints.

## Vision
To provide a transparent, efficient, and modern digital infrastructure for Bau-Bau's regional revenue management.
